## 🔧 Проверка перед запуском

### 1. Убедитесь, что телефон и компьютер в одной Wi-Fi сети

### 2. Проверьте доступность бэкенда с телефона

Откройте браузер на телефоне и перейдите:
```
http://192.168.2.155:8000/
```

**Должно вернуть:**
```json
{"status":"ok","service":"yess-backend","api":"/api/v1","docs":"/docs"}
```

✅ **Если видите JSON** - бэкенд доступен, всё должно работать!

❌ **Если не открывается** - проверьте Firewall (см. ниже)

---

## 🛡️ Проверка Windows Firewall

Если бэкенд не доступен с телефона, разрешите порт:

```powershell
# Запустите PowerShell от администратора
New-NetFirewallRule -DisplayName "Yess Backend" -Direction Inbound -LocalPort 8000 -Protocol TCP -Action Allow
```

---

## 🔄 Переключение между эмулятором и реальным телефоном

### Для эмулятора:
Установите переменную окружения перед запуском:
```powershell
$env:API_BASE_URL="http://10.0.2.2:8000/"
```

Или измените в `MauiProgram.cs` строку 105:
```csharp
return "http://10.0.2.2:8000/";  // Для эмулятора
```

### Для реального телефона:
Используйте IP вашего компьютера (по умолчанию: `192.168.2.155`)

---

## 📊 Проверка IP компьютера

Если `192.168.2.155` не работает, узнайте ваш IP:

```powershell
ipconfig | findstr /i "IPv4"
```

И замените в:
- `MauiProgram.cs` строка 105
- `ApiClient.cs` строка 38
