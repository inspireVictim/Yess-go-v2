## 📱 О проекте

**YESS Go Front** - мобильное приложение для программы лояльности

### Технологии
- **Платформа:** .NET MAUI 9.0
- **Целевые ОС:** Android и iOS
- **Архитектура:** MVVM (Model-View-ViewModel)
- **Язык:** C# 12

### Основные возможности
- 🔐 Аутентификация пользователей
- 💳 Управление балансом YesCoin
- 🏪 Каталог партнеров
- 🗺️ Карта с партнерами
- 📱 QR-код сканирование и оплата
- 🔔 Push-уведомления
- 📊 История транзакций

### Ключевые библиотеки
- `Microsoft.Maui.Controls` - UI фреймворк
- `CommunityToolkit.Mvvm` - MVVM паттерн
- `Mapsui.Maui` - Отображение карт
- `ZXing.Net.Maui` - QR-код сканер
- `Entity Framework Core` - Работа с БД
- `Npgsql` - PostgreSQL драйвер

## 🎯 Первые шаги после открытия

### 1. Выбор платформы для запуска

В Visual Studio, в верхней панели:
```
[Android ▼]  [Pixel 5 - API 33 ▼]  [▶ Start]
```

Выберите:
- **Android** - для разработки под Android
- **iOS** - для разработки под iOS (требуется Mac)

### 2. Настройка эмулятора

#### Для Android:
1. **Tools → Android → Android Device Manager**
2. Создайте виртуальное устройство или выберите существующее
3. Рекомендуется: Pixel 5, Android API 33 или выше

#### Для iOS:
Требуется подключение к Mac с Xcode через Remote iOS Simulator

### 3. Подключение к бэкенду

Убедитесь, что бэкенд запущен:

```powershell
# В новом окне PowerShell
cd E:\YessProject\Yess-Go-App-Backend\Yess-Money---app-master
docker compose up -d

# Проверить
curl http://localhost:8000/
```

Адрес бэкенда в приложении:
- **Для Windows:** `http://localhost:8000/api/v1`
- **Для Android эмулятора:** `http://10.0.2.2:8000/api/v1`
- **Для iOS симулятора:** `http://localhost:8000/api/v1`

Настройки находятся в: `Config/ApiEndpoints.cs`

## 🐛 Решение проблем

### Проблема: Ошибки восстановления пакетов
```bash
cd E:\YessProject\YessGoFrontV2
dotnet nuget locals all --clear
dotnet restore "YESS Go front v 2.0.sln"
```

### Проблема: Android SDK не найден
1. Откройте **Tools → Android → Android SDK Manager**
2. Установите Android SDK Platform 21+
3. Установите Android SDK Build-Tools
4. Перезапустите Visual Studio

### Проблема: Не видит целевую платформу
В Visual Studio Installer добавьте рабочую нагрузку:
- **.NET Multi-platform App UI development**

### Проблема: Ошибки сборки
```bash
# Полная очистка
Remove-Item -Recurse -Force bin, obj
dotnet clean
dotnet restore
dotnet build
```
