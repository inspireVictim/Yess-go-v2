# 🚀 Руководство по быстрой сборке проекта

## ⚡ Быстрые команды для сборки

### Сборка только Android (рекомендуется для разработки)
```bash
cd YessGoFrontV2
dotnet build -f net9.0-android
```

### Сборка только iOS
```bash
cd YessGoFrontV2
dotnet build -f net9.0-ios
```

### Сборка с использованием кэша (быстрее)
```bash
# Не используйте clean перед build - это удалит кэш!
dotnet build -f net9.0-android --no-incremental
```

### Полная пересборка (только при проблемах)
```bash
dotnet clean
dotnet restore
dotnet build -f net9.0-android
```

## 📊 Оптимизации, примененные к проекту

### 1. Параллельная сборка
- Включена параллельная сборка (`BuildInParallel=true`)
- Используется общая компиляция (`UseSharedCompilation=true`)

### 2. Кэширование
- Включено кэширование RID (`UseRidCache=true`)
- Включена инкрементальная сборка (`UseIncrementalBuild=true`)

### 3. Оптимизация ресурсов
- Оптимизирована обработка Android ресурсов
- Объединены кастомные таргеты для уменьшения операций

### 4. Упрощение конфигураций
- Backend solution оптимизирован (удалены лишние конфигурации платформ)

## ⏱️ Ожидаемое время сборки

- **Первая сборка (холодный старт)**: 2-5 минут
- **Инкрементальная сборка (после изменений)**: 30-90 секунд
- **Сборка одной платформы**: ~50% быстрее, чем обе платформы

## 💡 Советы для ускорения

1. **Не удаляйте папки bin/obj без необходимости**
   - Они содержат кэш для инкрементальной сборки

2. **Собирайте только нужную платформу**
   - Используйте `-f net9.0-android` или `-f net9.0-ios`

3. **Используйте Visual Studio Build**
   - Visual Studio автоматически использует инкрементальную сборку

4. **Избегайте полной пересборки**
   - Используйте `dotnet build` вместо `dotnet clean` + `dotnet build`

5. **Проверьте антивирус**
   - Исключите папки `bin`, `obj`, `.nuget` из сканирования

## 🔧 Устранение проблем

### Если сборка все еще медленная:

1. **Очистите кэш NuGet** (только при проблемах):
   ```bash
   dotnet nuget locals all --clear
   dotnet restore
   ```

2. **Проверьте версию .NET SDK**:
   ```bash
   dotnet --version
   ```
   Должна быть 9.0.305 (см. global.json)

3. **Проверьте свободное место на диске**:
   - MAUI проекты требуют много места для кэша

4. **Используйте SSD**:
   - Сборка на SSD значительно быстрее, чем на HDD
