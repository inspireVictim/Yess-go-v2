🚀 ЧТО НУЖНО СДЕЛАТЬ:

   (или файл: АВТОМАТИЧЕСКАЯ_ПЕРЕСБОРКА.bat)

3. Дождитесь завершения (это займет несколько минут)

5. Откройте Visual Studio:
   - Откройте файл YessGoFront.sln
   - Выберите net9.0-android в панели инструментов
   - Выберите эмулятор (например, "Pixel 7 - API 35")
   - Нажмите F5 для запуска
