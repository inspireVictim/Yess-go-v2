# 📱 Подключение физического телефона к Backend

## Текущая конфигурация

- **IP компьютера:** `192.168.2.155`
- **Backend URL:** `http://192.168.2.155:8000/`
- **Backend статус:** ✅ Запущен и доступен на `0.0.0.0:8000`

---

## Пошаговая инструкция

### Шаг 1: Настройте Windows Firewall

**ВАЖНО:** Firewall должен разрешать входящие подключения на порт 8000.

#### Вариант А: Автоматически (рекомендуется)

1. Откройте PowerShell **от имени администратора**:
   - Нажмите `Win + X`
   - Выберите "Windows PowerShell (Администратор)" или "Терминал (Администратор)"

2. Перейдите в папку проекта:
   ```powershell
   cd E:\YessProject\YessGoFrontV2
   ```

3. Запустите скрипт:
   ```powershell
   .\setup_firewall.ps1
   ```

#### Вариант Б: Вручную

1. Откройте "Брандмауэр Windows в режиме повышенной безопасности"
2. Выберите "Правила для входящих подключений"
3. Нажмите "Создать правило..."
4. Выберите "Для порта" → Далее
5. Выберите "TCP", укажите порт `8000` → Далее
6. Выберите "Разрешить подключение" → Далее
7. Отметьте все профили (Доменный, Частный, Публичный) → Далее
8. Имя: "Yess Backend API" → Готово

---

### Шаг 2: Проверьте подключение телефона к Wi-Fi

Убедитесь, что:
- ✅ Телефон подключен к той же Wi-Fi сети, что и компьютер
- ✅ Телефон находится в той же подсети (192.168.2.x)

**Проверка с телефона:**
1. Откройте браузер на телефоне
2. Перейдите по адресу: `http://192.168.2.155:8000/`
3. Должно открыться:
   ```json
   {
     "status": "ok",
     "service": "yess-backend",
     "api": "/api/v1",
     "docs": "/docs"
   }
   ```

Если не открывается:
- Проверьте, что компьютер и телефон в одной сети
- Проверьте firewall (Шаг 1)
- Перезапустите backend: `docker-compose restart backend`

---

### Шаг 3: Пересоберите и установите приложение

1. Откройте проект в Visual Studio

2. Выберите конфигурацию:
   - Target: Android
   - Configuration: Debug или Release

3. Подключите телефон через USB:
   - Включите "Отладку по USB" на телефоне
   - Разрешите отладку при подключении

4. Нажмите F5 или "▶ Start" для сборки и установки

---

### Шаг 4: Проверьте логи

После запуска приложения на телефоне:

1. Откройте `Output` → `Debug Output` в Visual Studio
2. Ищите строки:
   ```
   [MauiProgram] Emulator detection: False
   [MauiProgram] API BASE URL: http://192.168.2.155:8000/

3. Проверьте результат health check:

   ```
   или
   ```

   ```

## Решение проблем

### Проблема: "Connection refused" или таймаут

**Причина:** Backend недоступен из локальной сети.

**Решение:**
1. Проверьте firewall (см. Шаг 1)
2. Убедитесь, что backend запущен:
   ```powershell
   cd E:\YessProject\Yess-Go-App-Backend\Yess-Money---app-master
   docker-compose ps
   ```
3. Проверьте, что backend слушает на `0.0.0.0`:
   ```powershell
   docker-compose logs backend | Select-String -Pattern "Uvicorn running"
   ```
   Должно быть: `Uvicorn running on http://0.0.0.0:8000`

---

### Проблема: IP адрес изменился

**Причина:** IP компьютера может меняться при переподключении к Wi-Fi.

**Решение:**
1. Узнайте новый IP:
   ```powershell
   ipconfig | findstr "IPv4"
   ```
2. Обновите в `YessGoFrontV2/MauiProgram.cs` (строка 128):
   ```csharp
   var defaultPhoneUrl = "http://НОВЫЙ_IP:8000/";
   ```
3. Пересоберите приложение

---

### Проблема: Эмулятор тоже не работает

**Причина:** Код теперь настроен на физический телефон.

**Решение:** В `MauiProgram.cs` логика автоматически определяет эмулятор/телефон:
- **Эмулятор** → использует `10.0.2.2:8000`
- **Реальный телефон** → использует `192.168.2.155:8000`

Если эмулятор не определяется автоматически, проверьте логи:
```
[MauiProgram] Emulator detection: True/False
```
