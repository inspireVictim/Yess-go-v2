# 🚀 БЫСТРЫЙ ФИ́ЛЬ - СЕТЕВОЕ ПОДКЛЮЧЕНИЕ

## ❌ Проблема: Не получается войти/зарегистрироваться с другого устройства

---

## ✅ РЕШЕНИЕ (5 минут)

### Шаг 1: Узнайте ваш IP
```powershell
ipconfig
```
**Ищите строку:** `IPv4-?????: 192.168.X.X` (обычно начинается на 192.168)

**Запомните этот IP** → например `192.168.1.100`

---

### Шаг 2: Установите переменную окружения
```powershell
# Замените 192.168.1.100 на ВАШ IP!
$env:API_BASE_URL = "http://192.168.1.100:8000/"
```

---

### Шаг 3: Запустите приложение
```powershell
# Теперь запустите YessGoFront
.\YessGoFront.exe
```

---

### Шаг 4: Тест
```powershell
# Проверьте, что бэкенд доступен
curl http://192.168.1.100:8000/

# Должно вернуть (вместо ошибки):
# {"status":"ok","service":"yess-backend",...}
```

---

## 🔧 Если не сработало

### ❓ Вариант A: Docker не запущен
```powershell
# Проверить
docker ps | findstr "yess-backend"

# Если пусто - запустить
cd E:\YessProject\Yess-Go-App-Backend
docker-compose -f docker-compose.prod.yml up -d
```

### ❓ Вариант B: Неправильный IP
```powershell
# Проверить доступ
ping 192.168.X.X

# Если нет ответа - IP неверный
# Попросите IP у сисадмина или посмотрите в роутере
```

### ❓ Вариант C: Порт 8000 занят
```powershell
# Проверить
netstat -ano | findstr ":8000"

# Если запущен другой процесс - завершите его или измените порт
```

---

## 📝 Постоянная установка (чтобы не писать каждый раз)

```powershell
# Установить переменную окружения в Windows
[System.Environment]::SetEnvironmentVariable("API_BASE_URL", "http://192.168.1.100:8000/", "User")

# Перезагрузить PowerShell и проверить
$env:API_BASE_URL
```
