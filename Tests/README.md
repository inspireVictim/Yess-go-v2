# 🧪 Модульные тесты для блокировки emoji

Этот проект содержит модульные тесты для проверки функциональности блокировки emoji в Entry полях на Android.

## 📋 Описание

Тесты проверяют:
- ✅ Правильное определение emoji в тексте
- ✅ Корректное удаление emoji из строк
- ✅ Сохранение обычных символов при удалении emoji
- ✅ Обработку различных типов emoji (суррогатные пары и обычные символы)
- ✅ Обработку граничных случаев (пустые строки, null, смешанный контент)

## 🚀 Запуск тестов

### Windows (PowerShell)
```powershell
cd Tests
.\run_tests.ps1
```

### Linux/macOS (Bash)
```bash
cd Tests
chmod +x run_tests.sh
./run_tests.sh
```

### Прямой запуск через dotnet
```bash
cd Tests
dotnet test YessGoFront.EmojiFilter.Tests.csproj --verbosity normal
```

## 🔍 Что тестируется

### 1. Определение emoji (`ContainsEmoji`)
- Обычный текст без emoji
- Текст с emoji
- Различные типы emoji (😀, 👍, ❤, 🎉, 🚀)
- Граничные случаи (пустые строки, null)

### 2. Удаление emoji (`RemoveEmoji`)
- Удаление всех emoji из текста
- Сохранение обычных символов
- Обработка нескольких emoji подряд
- Обработка смешанного контента

### 3. Специальные случаи
- Суррогатные пары (emoji в диапазоне 0x1F300+)
- Обычные символы emoji (в диапазоне 0x2600-0x27BF)
- Unicode символы, которые НЕ являются emoji

## ⚠️ Важные замечания

1. **Тесты не требуют Android устройства** - они тестируют только логику определения emoji
2. **Тесты не проверяют интеграцию с EmojiCompat** - для этого нужны интеграционные тесты на реальном устройстве
3. **Символ ❤️ (с вариационным селектором)** может не определяться правильно - используйте ❤ (без селектора) для тестирования

## 🐛 Отладка

Если тесты не проходят:
1. Проверьте, что все пакеты установлены: `dotnet restore`
2. Проверьте сборку: `dotnet build`
3. Запустите тесты с подробным выводом: `dotnet test --verbosity detailed`
